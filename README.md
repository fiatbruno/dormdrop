# CSC 305 Project Starter Code

This repository contains backend and frontend code to use as a
starting point for Augustana's CSC 305 semester project.

You may use and modify this code however you see fit for your project.
You may also ignore this code and start from scratch if you wish,
although please see me first if you plan on using technologies other
than Spring Boot on the backend and React on the frontend.

The `backend` and `frontend` directories both contain their own
`README.md` files with more information specific to those parts.
